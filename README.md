# Geo Radius News 🗺️📰

**Geo Radius News** is a hyperlocal community-driven news platform that brings real-time verified updates from your surroundings. Whether it's politics, sports, weather, or breaking local stories — users can discover, read, and share updates like never before.

---

### Live Link: https://georadiusnews.vercel.app/

---

## 🚀 Features

- 🌍 HyperLocal News by Geo Radius
- 🔐 Authentication with Auth.js
- 📍 Location-based Permissions
- 🧠 AI-Powered Content Curation *(Coming Soon!)*
- 🎯 Reels-style Rapid Reading Mode
- ✏️ Add, Edit, and Hide News Posts
- 🔎 Full-text Search with Metadata SEO
- 📄 Category & Trending Pages
- 🎨 Responsive, Smooth UI with ShadCN
- 🧾 Legal Pages: T&C, Privacy Policy, Cookies, Guidelines
- 🛠️ Settings for 2FA, Password Change, Security, etc.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js App Router, React 18, TypeScript
- **UI Components:** Tailwind CSS, ShadCN
- **Authentication:** Auth.js
- **Backend API:** Built-in App Router Handlers
- **Database:** MongoDB (via Mongoose or Native)
- **State Management:** Zustand / useState
- **Deployment:** Vercel
- **Others:** Open Graph SEO, Dynamic Metadata, Server Components
